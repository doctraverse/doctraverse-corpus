Last updated: **2026-10-14**.

## Current public license

Unless a file or component carries a separate applicable license notice, the
materials in this repository are licensed under the **GNU Affero General Public
License, version 3 only (`AGPL-3.0-only`)**. The complete, unmodified license text
is in [LICENSE](LICENSE).

The project version notice above applies to this repository. The example notices
in the standard license's "How to Apply" appendix are instructions for authors,
not additional licensing terms for this project.

AGPL permits commercial use, redistribution, and paid hosting subject to its
conditions. Being a company or charging for a service does not by itself require
buying an alternative commercial license.

For a modified program that supports remote network interaction, section 13
requires a prominent offer of the Corresponding Source to users interacting
with it remotely. Distribution can create additional obligations under other
sections. Consult the full license for the applicable requirements.

## Planned alternative commercial license

The intended model is to offer eligible project code under either AGPL v3 or a
separate commercial agreement. A commercial agreement could grant permissions
that differ from AGPL, within the rights the licensor actually controls.

**No commercial license is currently offered or granted by this repository.**
Commercial terms, the contracting party, and the covered code scope are still
being prepared. An alternative grant would apply only after an appropriate
agreement is in place; an announcement or payment alone would not define it.

Adding a commercial alternative will not withdraw AGPL rights already granted
for published versions when the license conditions are met. Third-party code
retains its applicable license and cannot be relicensed through a promise about
the project as a whole.

## Enterprise features and hosting

An alternative license for the same core, separately licensed Enterprise
features, and a managed SaaS subscription are distinct arrangements.

| Area | Current position |
| --- | --- |
| Public repository materials | AGPL-3.0-only, except separately identified third-party material. |
| Alternative commercial terms for eligible core code | Planned; no commercial grant is active. |
| Enterprise features | Feature scope and terms are undecided; no Enterprise code is present. |
| Managed SaaS | Planned delivery option; no hosted service or subscription terms are available. |

There is no percentage-based licensing rule in this repository. Any future
exceptions must identify actual files or components and their applicable terms
before publication. A directory name such as `enterprise/` does not establish
a license or resolve compatibility of a combined work.

## Contributor and dependency rights

Dual licensing requires sufficient rights for the relevant code. Those rights
may come from ownership, an appropriate contributor agreement, or another
compatible grant. An ordinary AGPL contribution or DCO sign-off alone should
not be treated as permission to distribute the contribution under proprietary
terms.

See [CONTRIBUTING.md](CONTRIBUTING.md) for the current contribution policy and
the [licensing readiness plan](docs/licensing-readiness.md) for the work needed
before external contributions and a commercial offering.

The separate [Doc Traverse MCP](https://github.com/doctraverse/doctraverse)
project remains MIT-licensed. If its code is reused here, retain the relevant
MIT notices and record its provenance. This repository's license does not
change the license of the MCP repository.

## Documents processed by the software

The software license does not by itself transfer ownership of documents supplied
by users or place those documents under AGPL. Under section 2, program output
is covered only when its content constitutes a covered work. Input-document
rights, model-provider terms, and service data terms remain separate questions.
